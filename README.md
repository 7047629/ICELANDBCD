# תזכורות עבריות אוטומטיות — Google Sheets + Apps Script

טבלה אחת בגיליון, תאריך עברי בכל שורה, ומייל תזכורת שנשלח לבד בזמן:
**ביום האירוע / שבוע לפני / שבועיים לפני / כל מספר ימים שתבחרו / סדרה יומית עד תאריך** — כל שנה מחדש.

- 🗓️ התאריך העברי הוא יום+חודש, בלי שנה: הסקריפט ממיר אותו לתאריך לועזי בכל שנה עברית.
- ⏱️ רץ כל 5 דקות, אבל שולח פעם אחת בלבד לכל תזכורת (מניעת כפילויות מבוססת `LOG`).
- ✉️ שליחה במייל דרך Gmail, בעברית RTL, עם התאריך העברי והלועזי.
- 🧪 לוגיקת התאריכים נבדקה מול 1,890 תאריכי ייחוס (שנים 5750–5800) ו-999 ערכי גימטריה.

## התחלה מהירה

1. פותחים גיליון חדש ב-Google Sheets → **תוספים / Extensions → Apps Script**.
2. מדביקים את `src/HebrewDate.gs`, `src/Reminders.gs`, `src/Code.gs` כשני קבצי סקריפט (ואפשר גם את `appsscript.json` דרך *Project Settings*).
3. מריצים `setup()` ומאשרים הרשאות.
4. ממלאים שורות בגיליון **תזכורות** (נושא, יום עברי, חודש עברי, סימוני V).
5. מריצים `dryRunNow()` — רואים ב-`LOG` מה *היה* נשלח, בלי לשלוח. כשזה נראה נכון, `sendDueReminders()` שולח באמת.

הפירוט המלא, כולל הרשאות ופתרון תקלות: [`docs/SETUP.md`](docs/SETUP.md).

## איך נראית הטבלה

| מזהה | נושא | יום עברי | חודש עברי | תזכורת באותו יום | שבוע לפני | שבועיים לפני | ימים נוספים לפני | שעה | נמענים | פעיל | הערות | עד (ימים לפני) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `R2-a1b2c3d4` | יום הולדת של דנה | 15 | כסלו | ✓ | ✓ | ✓ | 30 | | | ✓ | להביא מתנה | |
| `R2-e5f6g7h8` | אזכרה לסבא | 3 | תשרי | ✓ | | | 30, 60 | 19:30 | moshe@example.com | ✓ | | 48 |

- **מזהה** נוצר אוטומטית בריצה הראשונה ומשמש למניעת שליחה כפולה. אין צורך לגעת בו.
- **ימים נוספים לפני** = רשימת מספרים מופרדת בפסיק (למשל `30, 60`), בנוסף לעמודות הסימון.
- **עד (ימים לפני)** = סדרה יומית: מספר שלם `N` שולח מייל בכל יום מ-N ימים לפני ועד התאריך עצמו, כולל. `48` = 49 מיילים רצופים, כמו ספירת העומר אישית (מומלץ לשלב עם שעת ערב בעמודת *שעה*). ריק = בלי סדרה, ויום שכבר מסומן בעמודות האחרות לא נשלח פעמיים.
- **שעה** ריקה = שעת ברירת המחדל מגיליון *הגדרות* (08:00).
- **נמענים** ריק = הנמענים מגיליון *הגדרות*.
- העמודות **תאריך לועזי** ו**התזכורת הבאה** מחושבות על ידי הסקריפט: התאריך הלועזי של השנה הנוכחית והתזכורת הבאה.

## איך זה עובד בקצרה

כל 5 דקות: קורא את השורות → ממיר יום+חודש עברי לתאריך לועזי (לשנה העברית הנוכחית ולזו שאחריה) → מחסיר את מספר הימים של כל תזכורת שסומנה → שולח את אלה שמועדן עבר וטרם נרשמו ב-`LOG` → רושם שורה ב-`LOG` עם מפתח ייחודי.

ההסבר המלא, כולל מדיניות אדר, יום 30 בחודש חסר, שעון קיץ ומכסות: [`docs/PLAN.md`](docs/PLAN.md).

## בדיקות

```bash
TZ=Asia/Jerusalem node tests/run-tests.js
```

אין תלויות — Node בלבד. אזור הזמן חייב להיות `Asia/Jerusalem`, בדיוק כמו המניפסט של הסקריפט, כדי שבדיקות שעון הקיץ יהיו נכונות.
