# התקנה, הפעלה ותפעול

מדריך צעד-אחר-צעד. הזמן הכולל: כ-10 דקות בפעם הראשונה.

---

## 0. מה צריך

- חשבון Google עם Gmail פעיל (המיילים יישלחו ממנו).
- גיליון Google Sheets חדש (או קיים) שאליו תדביקו את הסקריפט.
- דפדפן במחשב — ההתקנה לא נוחה מהאפליקציה בנייד.

---

## 1. הכנת הגיליון

1. פותחים [Google Sheets](https://sheets.google.com) ויוצרים גיליון חדש.
2. נותנים לו שם, למשל **תזכורות אישיות**.
3. לא צריך ליצור גיליונות פנימיים — `setup()` יעשה זאת.

---

## 2. הכנסת הקוד

1. מתוך הגיליון: **Extensions → Apps Script** (בעברית: **תוספים → Apps Script**).
2. נפתח פרויקט עם קובץ אחד בשם `Code.gs`. מוחקים את תוכן ברירת המחדל ומדביקים את
   תוכן [`../src/Code.gs`](../src/Code.gs).
3. לוחצים על **+** ליד *Files* → **Script**, נותנים שם `HebrewDate` ומדביקים את
   [`../src/HebrewDate.gs`](../src/HebrewDate.gs).
4. חוזרים על הפעולה: קובץ בשם `Reminders` עם [`../src/Reminders.gs`](../src/Reminders.gs).
5. שומרים (**Ctrl+S**).

> שמות הקבצים לא חייבים להיות זהים, אבל שם הקובץ `Code.gs` הוא ברירת המחדל ולכן נוח להשאירו.
> **חשוב:** אין לשנות את שמות הפונקציות — הטריגר קורא ל-`sendDueReminders` בשם.

---

## 3. המניפסט (אזור זמן והרשאות)

1. ב-Apps Script: **Project Settings** (גלגל שיניים) → מסמנים
   **"Show `appsscript.json` manifest file in editor"**.
2. חוזרים לעורך, נפתח קובץ `appsscript.json`. מחליפים את כולו בתוכן
   [`../src/appsscript.json`](../src/appsscript.json).
3. שומרים.

המניפסט קובע שני דברים קריטיים: `timeZone: "Asia/Jerusalem"` (בלעדיו שעות השליחה יזוזו)
וסקופי ההרשאה המינימליים.

---

## 4. הרצת `setup()`

1. בעורך, בתפריט הפונקציות למעלה, בוחרים **setup** ולוחצים **Run**.
2. נפתח חלון הרשאות → **Review permissions** → בוחרים את חשבון Google.
3. מופיעה אזהרה "Google hasn't verified this app" (כי זה סקריפט אישי):
   **Advanced → Go to \<שם הפרויקט\> (unsafe)** → **Allow**.
4. חוזרים לגיליון. אמורים להופיע:
   - גיליון **תזכורות** עם 15 כותרות, צ'קבוקסים ושורת דוגמה;
   - גיליון **הגדרות** עם 8 מפתחות;
   - גיליון **LOG** ריק עם כותרות;
   - תפריט חדש **תזכורות** בסרגל.
5. אם לא הופיע תפריט — רעננו את הדף (התפריט נטען ב-`onOpen`).

> `setup()` בטוח להרצה חוזרת: הוא משלים כותרות ומפתחות חסרים ולא דורס נתונים.

---

## 5. מילוי הטבלה

בגיליון **תזכורות**, כל שורה היא אירוע:

| עמודה | מה למלא |
| --- | --- |
| נושא | שם האירוע, למשל `יום הולדת של דנה`. |
| יום עברי | מספר בין 1 ל-30. |
| חודש עברי | שם בעברית: `תשרי`, `חשון`, `כסלו`, `טבת`, `שבט`, `אדר`, `ניסן`, `אייר`, `סיון`, `תמוז`, `אב`, `אלול`. בשנת מעובר אפשר `אדר א` / `אדר ב`. |
| תזכורת באותו יום / שבוע לפני / שבועיים לפני | לסמן ✓ היכן שרוצים תזכורת (אפשר כמה). |
| ימים נוספים לפני | אופציונלי: `30` או `30, 60`. |
| עד (ימים לפני) | אופציונלי: מספר שלם 0–365. למשל `48` = 49 מיילים יומיים, מה-48 ימים לפני ועד התאריך עצמו (כולל) — כמו ספירת העומר. ריק = אין סדרה. |
| שעה | אופציונלי: `19:30`. ריק = 08:00 מההגדרות. |
| נמענים | אופציונלי. ריק = הנמענים שבגיליון *הגדרות*. |
| פעיל | משאירים ✓. הסרה = השורה לא נשלחת. |
| הערות | אופציונלי, מופיע במייל. |

**חשוב:** לא לגעת בעמודות **מזהה**, **תאריך לועזי** ו**התזכורת הבאה** — הסקריפט כותב בהן.

לפני שממשיכים, מלאו בגיליון **הגדרות** את `defaultRecipients` (המייל שלכם), אחרת לא יהיה
למי לשלוח.

---

## 6. בדיקה יבשה (בלי לשלוח)

1. בגיליון: **תזכורות → בדיקה יבשה (בלי מיילים)**.
2. עברו לגיליון **LOG**. אם היה משהו שהיה נשלח עכשיו — מופיעה שורה עם
   `יבש (לא נשלח)`; אם לא — ה-`LOG` נשאר ריק וזה תקין (אין תזכורת שבמועדה).
3. רוצים לראות תזכורת בוודאות? הוסיפו שורה עם **התאריך העברי של היום** וסמנו
   "תזכורת באותו יום", ואז הריצו בדיקה יבשה שוב.

אפשר לראות את פרטי הריצה ב-Apps Script → **Executions** (כולל שורות `Logger.log`).

---

## 7. שליחה אמיתית ראשונה

1. **תזכורות → שלח עכשיו**.
2. המייל אמור להגיע תוך שניות. אם לא — ראו §10.
3. הריצו **שלח עכשיו** פעם שנייה: **לא** אמור להישלח מייל נוסף, וב-`LOG` לא מתווספת שורה
   חדשה עם אותו מפתח. זו ההוכחה שמניעת הכפילויות עובדת.

---

## 8. הפעלת הטריגר

`setup()` כבר מתקין טריגר של 5 דקות. כדי לוודא:

1. Apps Script → **Triggers** (שעון מעל סרגל הצד).
2. אמורה להופיע שורה אחת: `sendDueReminders` · *Time-driven* · *Minutes timer* · *Every 5 minutes*.

אם אין — **תזכורות → התקנת טריגר (5 דקות)**.

מכאן והלאה אין מה לעשות: השורות שיסומנו יקבלו מייל בזמן, כל שנה מחדש.

---

## 9. תפעול שוטף

| פעולה | איך |
| --- | --- |
| להוסיף תזכורת | שורה חדשה בגיליון. אין צורך לגעת בסקריפט. |
| להפסיק תזכורת | להסיר ✓ מ"פעיל" (השורה נשארת בארכיון). |
| לשנות שעה לכולם | גיליון *הגדרות* → `sendTime`. |
| לשנות שעה לאירוע אחד | עמודה "שעה". |
| לשנות נוסח נושא | גיליון *הגדרות* → `subjectTemplate`. |
| לעצור הכול | **תזכורות → הסרת טריגר**. |
| לבדוק מה נשלח ומתי | גיליון **LOG**. |
| לראות תקלות | Apps Script → **Executions**, מסונן לפי `Failed`. |
| לגבות | הגיליון עצמו. אפשר גם *File → Make a copy*. |

## 10. פתרון תקלות

| תסמין | סיבה סבירה | מה עושים |
| --- | --- | --- |
| לא מגיע מייל, וה-`LOG` ריק | אין תזכורת שבמועדה, או שהשורה לא "פעילה" | בדקו שה-✓ בעמודה "פעיל", ושהתאריך אכן מגיע בזמן הקרוב. הריצו `dryRunNow()`. |
| `LOG` מציג `שגיאה: לא הוגדרו נמענים` | אין נמענים בשורה וגם לא ב-`defaultRecipients` | מלאו `defaultRecipients` בגיליון *הגדרות*. |
| `LOG` מציג `Service invoked too many times ... email` | נגמרה מכסת המיילים היומית (100 בחשבון חינמי) | המתינו ליום הבא או שדרגו ל-Workspace. התזכורת תנוסה אם עוד בתוך `graceHours`. |
| `Exceeded maximum execution time` | יותר מדי שורות / יותר מדי שליחות בריצה | הקטינו `maxSendsPerRun`, או העלו את הטריגר ל-10–15 דקות (ראו PLAN §8). |
| המייל מגיע בשעה לא נכונה | אזור זמן שונה בגיליון או במניפסט | הריצו `setup()` שוב ובדקו ש-`appsscript.json` כולל `"timeZone": "Asia/Jerusalem"`. |
| "אין הרשאות" / `Authorization is required` | ההרשאות לא אושרו אחרי שינוי מניפסט | הריצו פונקציה כלשהי, אשרו מחדש את המסך. |
| שורה לא נשלחת ואין לה סיבה | חודש לא מזוהה, יום לא תקין, שעה לא תקינה | הריצו `dryRunNow()` וקראו את **Executions** — שם מפורטת הסיבה לכל שורה שנדחתה. |
| נשלחו שני מיילים לאותה תזכורת | שינוי תאריך בין הריצות, או שני פרויקטים על אותו גיליון | ראו PLAN §7; בדקו שיש פרויקט אחד ו-`LOG` אחד. |
| הטריגר נעלם | הפרויקט הועתק/שוחזר | **תזכורות → התקנת טריגר**. |

---

## 11. בדיקות מקומיות (אופציונלי, למפתחים)

```bash
TZ=Asia/Jerusalem node tests/run-tests.js
```

אין צורך ב-`npm install` — הבדיקות טוענות את קבצי ה-`.gs` כמו שהם ומוודאות המרות תאריך
מול 1,890 תאריכי ייחוס, את חלון ההשלמה, מניעת כפילויות, שעון קיץ ובניית המייל.
אם משנים את הקוד — זו הבדיקה הראשונה שמריצים.

> ב-Windows המילה `TZ=` בסוף הפקודה לא משפיעה (Node מתעלם ממנה שם) — אזור הזמן נגזר
> מהגדרת המערכת, והבדיקה מוודאת שהוא `Asia/Jerusalem`. ב-macOS/Linux משתנה הסורביה תקף.

---

## 12. הסרה

1. **תזכורות → הסרת טריגר** (עוצר את השליחה).
2. Apps Script → **Project Settings → Delete project** (מוחק את הקוד).
3. מחיקת הגיליון (או השארתו כארכיון).

אין שרת, אין מפתחות ואין שירותים חיצוניים שנשארים מאחור.
